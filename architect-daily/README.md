# Architect Daily episodes
One folder per episode: `<date>/episode.json`, the two HyperFrames projects (`16x9/`, `9x16/`) and `out/` (MP4s, QA frames, VERIFY.md).
Make a new one with the `architect-daily-reel` skill (`.agents/skills/architect-daily-reel/SKILL.md`):
`node .agents/skills/architect-daily-reel/scripts/make-reel.cjs <episode.json> --out architect-daily`
